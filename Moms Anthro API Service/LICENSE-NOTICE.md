# Included WHO Anthro package

`vendor/anthro_1.1.0.zip` is the World Health Organization's Anthro R package
version 1.1.0 supplied with this project. Its package metadata declares the
GPL-3 license. This API is only a transport wrapper; it does not modify the
WHO growth-standard calculation methods or claim clinical certification.

Use the results alongside the relevant WHO guidance and qualified clinical
judgement. MOMS should retain the original measurement, date, and any quality
flags returned by the service.
